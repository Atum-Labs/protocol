# Stellar (Soroban) contracts

Atum Protocol escrow and fulfillment proxy for Soroban. Behaviour follows the EVM
contracts; the byte framing of signed messages follows the Solana port.

- `source/contracts/escrow`: deposit, release, refund, token config and fees, roles, pause.
- `source/contracts/fulfillment_proxy`: fulfill, strict fulfill, authorize fulfillment.
- `source/docs/witness-layouts.md`: byte-exact digest layouts and golden vectors (the encoder contract).
- `bindings/{go,typescript}/escrow-encoding`: the off-chain digest encoders.
- `conformance/`: the shared vectors and `regenerate_vectors.py`. `vectors.json` (the digest vectors) is
  generated by `regenerate_vectors.py`, the out-of-band oracle. `guard-vectors.json` (encoder rejections) and
  `strkey-vectors.json` (strkey decoding cases) are hand-written. See `../encoding-parity.md`.
- `deploy/README.md` and `source/scripts/`: deploy, TTL keeper and smoke tooling (run on a local Protocol 30 network and on testnet, scenarios included, see the deploy README's Status; not yet on mainnet).
- `source/docs/DECISIONS.md`: design decisions.

```sh
cd contracts/stellar/source
cargo test -p escrow
cargo clippy -p escrow --all-targets -- -D warnings
cargo fmt -p escrow --check
# Release wasm: soroban-sdk 30 needs stellar-cli v30.0.0+; the pinned toolchain and hashes are in
# ../deploy/README.md, "Reproducible build"
stellar contract build
```

```sh
cd contracts/stellar
python3 conformance/regenerate_vectors.py --check   # vectors.json matches the layout doc
(cd bindings/go/escrow-encoding && go test ./...)
(cd bindings/typescript/escrow-encoding && pnpm test)
```

**SDK version:** the contracts use soroban-sdk 30 (Protocol 30, Bell). It is pinned to `=30.0.0-rc.1`, a release
candidate, and the audit freezes on it; if stable 30.0.0 is published before the fix re-review, the change from rc.1
to stable is reviewed then. Testnet is on Protocol 30, and mainnet upgrades after its vote. Tests and clippy were run with SDK 30; the wasm build needs stellar-cli 30+; see "Reproducible build" in
`deploy/README.md` and `source/docs/DECISIONS.md`.

The hash-anchor tests in `contracts/escrow/src/test_anchors.rs` pin every digest. Never regenerate their
constants from the code's output; see the header of that file and `contracts/encoding-parity.md`.
