# CORE-2388 (2026-09-11) — `extra.atum.issuedAt` removed from the atum-escrow
# scheme. The merchant no longer stamps the Solana deposit's issue time; the payer
# derives it at signing time, from the cluster clock the escrow judges it against.
# A request that still carries the property is refused, deliberately: the `extra`
# schema is closed, and silence would let a merchant reintroduce a field that makes
# any payment crossing a wall-clock second unmatchable.
POST /verify removed the request property `paymentRequirements/extra/atum/issuedAt`
POST /settle removed the request property `paymentRequirements/extra/atum/issuedAt`

# requirement carries `extra.atumResource`, which client and facilitator fold into

# server and facilitator move to 0.6.0 together.
